2) Baseline snapshot (what is running + what is listening):
Gives you proof of what was running and helps if you need to roll back
“Get-NetTCPConnection -State Listen |
  Sort-Object LocalPort |
  Select-Object LocalAddress,LocalPort,OwningProcess |
  Out-File C:\BlueTeam\listening_ports.txt

Get-Service | Where-Object Status -eq "Running" |
  Sort-Object Name |
  Out-File C:\BlueTeam\running_services.txt”

5) Firewall
5A) Export first so you can roll back fast
mkdir C:\BlueTeam
netsh advfirewall export "C:\BlueTeam\firewall_before.wfw"
5B) Enable allow rules FIRST
Enable-NetFirewallRule -DisplayGroup "Remote Desktop" 
Rollback command if anything breaks
netsh advfirewall import "C:\BlueTeam\firewall_before.wfw"
On Armory (IIS):
Enable-NetFirewallRule -DisplayGroup "World Wide Web Services (HTTP Traffic-In)" 
Enable-NetFirewallRule -DisplayGroup "World Wide Web Services (HTTPS Traffic-In)" 
On Sewers (SMB):

5C) Turn the firewall on
